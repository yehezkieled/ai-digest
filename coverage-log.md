# Coverage Log

Tracks everything the daily digest has reported. The routine reads this before each run and
skips items already listed here — unless there's been a meaningful update (new capability,
major version, changed best practice).

**Format:** append one row per reported item after each run. For an [Update], change the
"Last Meaningful Update" column; do not add a duplicate row.
